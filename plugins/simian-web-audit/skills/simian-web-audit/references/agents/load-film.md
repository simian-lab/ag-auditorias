# Agent: load comparison page (optional block)

The page itself is generated by `scripts/build_load_page.py` from Lighthouse data; no agent is needed when the benchmark agent already produced `raw/bench-<slug>-lh.json` for each competitor.

Only if some competitor Lighthouse file is missing or has no `screenshot-thumbnails`, run for that competitor:

`lighthouse URL --quiet --chrome-flags="--headless=new" --form-factor=mobile --output=json --output-path=raw/bench-<slug>-lh.json`

Use the same `slug` as in `findings/benchmark.json`. Then run `build_load_page.py`, open `report/feature-carga.html` with headless Chrome at 1440 wide and check:
- the headline matches the data (it is generated from observed times);
- every row shows frames, and frames before first paint read "En blanco";
- recorded times drive the clock; the simulated (slow 4G) Lighthouse metrics appear only in the captioned table.

Reply only with the file path and the observed LCP per site.
