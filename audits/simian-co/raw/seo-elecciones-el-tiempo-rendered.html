Elecciones El Tiempo 2026

Creamos una aplicación web que, mediante un modelo matemático, permite identificar la afinidad de los votantes con las propuestas de los candidatos a la presidencia.

Cliente: El Tiempo

Sector: Medios de comunicación

El cliente

El Tiempo

Se trata del medio informativo más influyente de Colombia, con un robusto ecosistema digital y audiencias masivas. Su equipo editorial impulsa productos interactivos de alto impacto y gran alcance en toda Colombia.

El reto

Crear un test interactivo, ágil y confiable que procesara respuestas en segundos, aplicando un modelo matemático verificable para medir afinidad.

El desafío fue convertir 13 preguntas en una experiencia fluida, capaz de calcular resultados al instante. Implementamos el motor de afinidad usando distancia Manhattan ponderada y una escala Likert de 5 puntos, para entregar un porcentaje de 0% a 100%. La lógica contrasta respuestas del usuario con posiciones de precandidatos construidas por verificación periodística de declaraciones y programas.

La solución

  • Una aplicación web en React, optimizada para carga rápida y respuesta inmediata.
  • Cuestionario de 13 preguntas con escala Likert (1–5) para capturar matices.
  • Motor de afinidad implementado con distancia Manhattan ponderada para una comparación consistente.
  • Cálculo automático contra una base de precandidatos, con enfoque informativo.
  • Preguntas organizadas por dimensiones temáticas para estructurar el análisis y facilitar interpretación.
  • Resultado expresado en porcentaje de afinidad (0%–100%) para visualizar cercanía programática.
  • Arquitectura modular (interfaz + motor de cálculo) para mantenimiento, iteraciones y escalabilidad.

¿Qué logramos?

Hicimos posible que la audiencia de eltiempo.com pueda tomar mejores decisiones informadas respecto a las elecciones presidenciales.

  • Comparación clara entre respuestas del usuario y posturas de precandidatos.
  • Resultados fáciles de interpretar que ayudan a reflexionar antes de decidir.
  • Experiencia rápida que permite completar el test sin fricción.
  • Confianza por metodología trazable y lógica consistente detrás del cálculo.
  • Base lista para actualizarse y evolucionar con el avance de la contienda.
